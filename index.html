<roll-dice>

A drop-in web component for tabletop RPG sites. Click a die to roll.

In a sentence: attack for 1d20+5 and deal 2d6+3 damage. Roll your stats with 4d6kh3, or with advantage: 2d20kh1.

Freeform roller

The <roll-any-dice> element is a button that opens a builder where you can add and remove any dice, then roll the pool. Like every widget on this page it is a plain in-flow element; here the page pins it to the bottom-right corner with three lines of CSS (position: fixed on the host).

Roll log

Every roll is saved to localStorage (last 50) and survives page reloads. The roll overlay always shows the history in its bottom-left corner; the <roll-log> element shows the same log wherever you drop it — expand it right here:

Battle mat

The <battle-mat> button opens a full-screen grid map: drag player and monster tokens from the pool, draw with pen and shapes, measure with the ruler, attach a map image and align the grid to it. The map autosaves to localStorage as a JSON Canvas document and can be exported/imported as a .canvas file. The map code loads lazily — nothing is fetched until the first open.

Add to battle

The <add-to-battle> button belongs on content pages (a bestiary entry, a character sheet). Every click adds one more instance of the creature to the persistent pool feeding the mat's Party/Foes tabs — the second wolf gets a random adjective ("Reckless Wolf") so you can tell them apart. The badge counts instances; remove them with the × buttons in the mat's pool.

Initiative tracker

The <initiative-tracker> element shares the battle mat's encounter document. Try it end to end:

  1. Open the battle mat above and drag a few party and monster tokens onto the grid, then close it (Escape).
  2. Expand the tracker below — every token is a combatant, color-coded like its ring on the mat.
  3. Type initiative values: the list re-sorts descending as you go.
  4. Next walks the turn order and bumps the round counter when it wraps; Reset returns to round one keeping the rolls.

Everything is one shared document: rename or delete tokens on the mat and the tracker follows, in this tab and in other open tabs. Exporting the map from the mat carries the turn state with it.

Install

Drop-in via a <script> tag, no build step or npm needed:

<script type="module"
  src="https://ramil-k.github.io/dice-roller/roll-dice.js"></script>

<roll-dice>2d6+3</roll-dice>

Or install from npm:

npm install @ramilkos/roll-dice
import '@ramilkos/roll-dice';

Supported syntax: NdM, dM, +K/-K, multiple terms, and keep/drop (kh/kl/dh/dl).
