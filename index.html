<roll-dice>

A drop-in web component for tabletop RPG sites. Click a die to roll.

In a sentence: attack for 1d20+5 and deal 2d6+3 damage. Roll your stats with 4d6kh3, or with advantage: 2d20kh1.

Freeform roller

The <roll-any-dice> element adds a floating button (bottom-right of this page) that opens a builder where you can add and remove any dice, then roll the pool.

Roll log

Every roll is saved to localStorage (last 50) and survives page reloads. The roll overlay always shows the history in its bottom-left corner; the <roll-log> element (bottom-left of this page) shows the same log on the page.

Roll events

The component emits a bubbling roll event you can log to a chat, etc.

(roll something to see the event)

Install

Drop-in via a <script> tag, no build step or npm needed:

<script type="module"
  src="https://ramil-k.github.io/dice-roller/roll-dice.js"></script>

<roll-dice>2d6+3</roll-dice>

Or install from npm:

npm install @ramilkos/roll-dice
import '@ramilkos/roll-dice';

Supported syntax: NdM, dM, +K/-K, multiple terms, and keep/drop (kh/kl/dh/dl).
